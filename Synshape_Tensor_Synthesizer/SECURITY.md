# Security Policy for Synshape Tensor Synthesizer

## Supported Versions

Currently, only the latest version of the main branch is actively supported with security updates.
Since the **Synshape Tensor Synthesizer** is a local-first application running strictly in the browser with no backend infrastructure, the attack surface is naturally minimal. However, we take all potential security issues very seriously.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please **do not** open a public issue. We appreciate your efforts to responsibly disclose your findings to keep the architecture secure.

Please report all security vulnerabilities via email directly to:
👉 **mbarlozewski@gmail.com**

Alternatively, contact the lead architect **Michael Barlozewski | g.dev/avx** directly.

We will acknowledge receipt of your vulnerability report as soon as possible and strive to send you regular updates about our progress. If the issue is confirmed, a patch will be developed and released.

Thank you for helping keep the Synshape Tensor Synthesizer secure and clean!
